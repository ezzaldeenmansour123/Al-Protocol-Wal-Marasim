## PROTOCOL AI (أعلى أولوية)
- نموذج لغوي حقيقي (عربي/إنجليزي)، فهم وتحليل واستدلال وصياغة جديدة ومهام متعددة الخطوات، بنية قابلة لتبديل المزود مستقبلاً.
- طبقة اتصال مستقلة، لا مفاتيح API مكشوفة داخل التطبيق، خادم وسيط آمن عند الإمكان، حالة اتصال واضحة، لا إجابة وهمية عند فشل الاتصال، ولا ادعاء عمل دون إنترنت إن كان سحابياً.
- قاعدة معرفة موثقة (نص + مصدر أصلي + جهة ناشرة + رابط + تاريخ مراجعة + تصنيف + نطاق)، مصنفة: قواعد قانونية ملزمة / ممارسات شائعة / أعراف محلية / إرشادات تنظيمية / اجتهادات غير ملزمة — دون خلط.
- آلية إجابة: فهم، تحديد المجال، استرجاع، فحص موثوقية، تحليل، تكوين إجابة، إرفاق مصادر، توضيح النقص/التعارض. شكل الإجابة: مباشرة + شرح + قاعدة + تطبيق عملي + تحذيرات + مصادر.
- مهام عملية: برنامج زيارة، جدول اجتماع، قائمة استقبال، ترتيب جلوس، مراجعة أعلام، صياغة خطاب، دعوة، مذكرة شفوية، برنامج توقيع، مراجعة خطة، اكتشاف أخطاء، حلول بديلة، قوائم تحقق.
- منع الاختلاق إلزامي: عند غياب معلومات موثوقة يقول «لا تتوفر في قاعدة المعرفة الحالية معلومات موثوقة وكافية للإجابة عن هذا السؤال.» ممنوع اختراع مواد/اتفاقيات/ألقاب/مصادر، أو تقديم الأعراف كقوانين، أو تأكيد معلومات خاطئة، أو تقديم احتمالات كحقائق. التعارض يُوضَّح لا يُخفى.
- RAG: فصل النموذج عن محرك البحث وقاعدة المعرفة والتوثيق. SQLite + FTS5 محلياً، مع إمكانية بحث دلالي لاحقاً. v1: بحث محلي + مصادر مخزنة + جلب حديث عند توفر خدمة + تاريخ آخر تحديث + لا مصادر غير موجودة.
